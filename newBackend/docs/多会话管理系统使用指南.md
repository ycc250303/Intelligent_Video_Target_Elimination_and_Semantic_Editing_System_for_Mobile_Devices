# 多会话管理系统使用指南

## 📖 概述

CoEdit 智能视频编辑系统现在支持**多会话管理**和**并发任务处理**，允许用户创建多个独立的对话会话，每个会话可以并行处理不同的视频编辑任务。

## 🌟 核心特性

### 1. 多会话支持
- ✅ 每个用户可创建多个独立会话
- ✅ 每个会话有独立的消息历史
- ✅ 会话数据持久化存储
- ✅ 支持会话的增删改查

### 2. 并发任务处理
- ✅ 最多同时运行 4 个任务
- ✅ 异步/同步执行模式可选
- ✅ 完整的任务状态跟踪
- ✅ 任务可取消

### 3. 前后端一致性
- ✅ 后端会话模型与前端 `Project` 模型对应
- ✅ 消息结构完全兼容
- ✅ 相同的时间戳格式

## 💻 Python 客户端示例

### 基础使用

```python
import requests

BASE_URL = "http://localhost:8000/api/v2"

# 1. 创建会话
response = requests.post(f"{BASE_URL}/sessions/create", json={
    "user_id": "user123",
    "title": "视频剪辑任务",
    "icon": "🎬"
})
session = response.json()["session"]
session_id = session["id"]

# 2. 处理视频（同步）
with open("video.mp4", "rb") as video_file:
    response = requests.post(
        f"{BASE_URL}/sessions/process-multimodal",
        data={
            "session_id": session_id,
            "text": "剪掉前3秒",
            "execute_async": "false"
        },
        files={"video": video_file}
    )
    result = response.json()
    print(f"处理结果: {result}")

# 3. 获取会话历史
response = requests.get(f"{BASE_URL}/sessions/{session_id}")
session_data = response.json()["session"]
print(f"消息数量: {len(session_data['messages'])}")
```

### 异步处理示例

```python
import requests
import time

BASE_URL = "http://localhost:8000/api/v2"

# 1. 提交异步任务
with open("video.mp4", "rb") as video_file:
    response = requests.post(
        f"{BASE_URL}/sessions/process-multimodal",
        data={
            "session_id": session_id,
            "text": "添加水印",
            "execute_async": "true"
        },
        files={"video": video_file}
    )
    task_id = response.json()["task_id"]
    print(f"任务已提交: {task_id}")

# 2. 轮询任务状态
while True:
    response = requests.get(f"{BASE_URL}/tasks/{task_id}")
    task = response.json()["task"]
    status = task["status"]
    
    print(f"任务状态: {status}")
    
    if status in ["completed", "failed", "cancelled"]:
        break
    
    time.sleep(2)  # 每2秒检查一次

# 3. 获取结果
if task["status"] == "completed":
    print(f"输出文件: {task['output_path']}")
    print(f"耗时: {task['execution_time']}秒")
else:
    print(f"任务失败: {task['error_message']}")
```

### 批量并发处理

```python
import requests
from concurrent.futures import ThreadPoolExecutor

BASE_URL = "http://localhost:8000/api/v2"

def process_video(session_id, video_path, instruction):
    """处理单个视频"""
    with open(video_path, "rb") as video_file:
        response = requests.post(
            f"{BASE_URL}/sessions/process-multimodal",
            data={
                "session_id": session_id,
                "text": instruction,
                "execute_async": "true"
            },
            files={"video": video_file}
        )
        return response.json()["task_id"]

# 创建多个会话
user_id = "user123"
sessions = []
for i in range(3):
    response = requests.post(f"{BASE_URL}/sessions/create", json={
        "user_id": user_id,
        "title": f"批量任务 {i+1}"
    })
    sessions.append(response.json()["session"]["id"])

# 并发提交任务
videos = ["video1.mp4", "video2.mp4", "video3.mp4"]
instructions = ["剪掉前3秒", "调整速度为1.5倍", "添加淡入淡出效果"]

task_ids = []
with ThreadPoolExecutor(max_workers=3) as executor:
    futures = [
        executor.submit(process_video, session_id, video, instruction)
        for session_id, video, instruction in zip(sessions, videos, instructions)
    ]
    task_ids = [f.result() for f in futures]

print(f"已提交 {len(task_ids)} 个任务")

# 监控所有任务
import time
while True:
    # 检查执行器状态
    response = requests.get(f"{BASE_URL}/executor/stats")
    stats = response.json()["stats"]
    
    print(f"\n执行器状态:")
    print(f"  运行中: {stats['running']}")
    print(f"  等待中: {stats['pending']}")
    print(f"  已完成: {stats['completed']}")
    
    if stats['running'] == 0 and stats['pending'] == 0:
        break
    
    time.sleep(3)

print("\n所有任务完成!")
```

## 🔄 与前端集成

### 前端模型映射

前端 `Project` 模型 ↔ 后端 `Session` 模型：

| 前端字段    | 后端字段     | 说明        |
| ----------- | ------------ | ----------- |
| `id`        | `id`         | 项目/会话ID |
| `title`     | `title`      | 标题        |
| `icon`      | `icon`       | 图标        |
| `status`    | `status`     | 状态        |
| `progress`  | `progress`   | 进度        |
| `messages`  | `messages`   | 消息列表    |
| `createdAt` | `created_at` | 创建时间    |
| `updatedAt` | `updated_at` | 更新时间    |

### Flutter 集成示例

```dart
import 'package:http/http.dart' as http;
import 'dart:convert';

class BackendSessionService {
  static const String baseUrl = "http://your-server:8000/api/v2";
  
  // 创建会话
  static Future<Map<String, dynamic>> createSession(String userId) async {
    final response = await http.post(
      Uri.parse('$baseUrl/sessions/create'),
      headers: {'Content-Type': 'application/json'},
      body: jsonEncode({
        'user_id': userId,
        'title': '新对话 ${DateTime.now().toString()}',
        'icon': '🎬'
      }),
    );
    
    return jsonDecode(response.body);
  }
  
  // 获取用户会话
  static Future<List<dynamic>> getUserSessions(String userId) async {
    final response = await http.get(
      Uri.parse('$baseUrl/users/$userId/sessions'),
    );
    
    final data = jsonDecode(response.body);
    return data['sessions'];
  }
  
  // 处理视频（异步）
  static Future<String> processVideo({
    required String sessionId,
    required String text,
    required String videoPath,
  }) async {
    var request = http.MultipartRequest(
      'POST',
      Uri.parse('$baseUrl/sessions/process-multimodal'),
    );
    
    request.fields['session_id'] = sessionId;
    request.fields['text'] = text;
    request.fields['execute_async'] = 'true';
    request.files.add(await http.MultipartFile.fromPath('video', videoPath));
    
    final response = await request.send();
    final responseData = await response.stream.bytesToString();
    final data = jsonDecode(responseData);
    
    return data['task_id'];
  }
  
  // 获取任务状态
  static Future<Map<String, dynamic>> getTaskStatus(String taskId) async {
    final response = await http.get(
      Uri.parse('$baseUrl/tasks/$taskId'),
    );
    
    return jsonDecode(response.body);
  }
}
```

## 📊 数据结构

### Session (会话)
```python
{
  "id": str,              # 会话ID
  "user_id": str,         # 用户ID  
  "title": str,           # 标题
  "icon": str,            # 图标emoji
```

```python
{
  "id": str,              # 消息ID
```

## 📝 注意事项

1. **会话数据持久化**：会话数据保存在 `data/sessions/` 目录下
2. **并发限制**：默认最多4个并发任务，可在 `concurrent_task_executor.py` 中调整
3. **文件清理**：定期清理已完成的任务和旧会话，避免磁盘占用过多
4. **线程安全**：所有管理器都使用了线程锁，支持并发访问

## 🔍 故障排查

### 问题1: 任务一直处于pending状态
**原因**：所有工作线程都在忙
**解决**：等待其他任务完成，或增加 `max_workers`

### 问题2: 会话创建失败
**原因**：磁盘空间不足或权限问题
**解决**：检查 `data/sessions/` 目录权限

### 问题3: 任务结果丢失
**原因**：任务完成后被清理
**解决**：及时获取任务结果，不要依赖长期存储
