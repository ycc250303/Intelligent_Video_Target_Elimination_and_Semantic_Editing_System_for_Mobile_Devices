## 第2层：会话列表层 (Sessions/Projects List)

### 前端设计（Flutter）

**模型名称**：`List<Project>`

**存储方式**：
```dart
class ProjectService {
  static const String _projectsKey = 'saved_projects';
  
  Future<List<Project>> getAllProjects() async {
    final prefs = await SharedPreferences.getInstance();
    final projectsJson = prefs.getStringList(_projectsKey) ?? [];
    return projectsJson.map((json) => Project.fromJson(json)).toList();
  }
}
```

**数据格式**：
```dart
// SharedPreferences中存储为字符串列表
List<String> projectsJson = [
  '{"id":"project_1","title":"项目1",...}',
  '{"id":"project_2","title":"项目2",...}',
  // ...
]
```

### 后端设计（Python）- 单用户模式

**模型名称**：`List[Session]`

**存储方式**：
```python
class SessionManager:
    sessions: Dict[str, Session]  # session_id -> Session
    # ✅ 已移除：user_sessions
    
    def get_all_sessions(self) -> List[Session]:
        """获取所有会话 - 无需user_id参数"""
        sessions = list(self.sessions.values())
        sessions.sort(key=lambda s: s.updated_at, reverse=True)
        return sessions
```

**数据格式**：
```python
# 文件系统结构（简化）
data/sessions/
├── session_1234567890_abc123.json
├── session_1234567891_def456.json
└── session_1234567892_ghi789.json

# 无需用户索引
```

**对应关系**：

| `List<Project>`    | `List[Session]`      | ✅ 完全对应     |

| `saveProject()`    | `create_session()`   | ✅ 功能一致     |
| `deleteProject()`  | `delete_session()`   | ✅ 功能一致     |

**排序方式**：
- 前端：✅ 按 `updatedAt` 降序
- 后端：✅ 按 `updated_at` 降序
- 对接：✅ 一致

**参数对比**：

#### 2. 添加状态映射函数
```dart
// lib/utils/status_mapper.dart
class StatusMapper {
  // 后端 → 前端
  static String fromBackend(String backendStatus) {
    const map = {
      'active': '进行中',
      'idle': '空闲',
      'processing': '处理中',
      'completed': '已完成',
      'error': '错误',
    };
    return map[backendStatus] ?? '进行中';
  }
  
  // 前端 → 后端
  static String toBackend(String frontendStatus) {
    const map = {
      '进行中': 'active',
      '空闲': 'idle',
      '处理中': 'processing',
      '已完成': 'completed',
      '错误': 'error',
    };
    return map[frontendStatus] ?? 'active';
  }
}
```

#### 3. 添加时间格式转换
```dart
// lib/utils/time_converter.dart
class TimeConverter {
  // DateTime → ISO8601字符串
  static String toIso(DateTime dt) => dt.toIso8601String();
  
  // ISO8601字符串 → DateTime
  static DateTime fromIso(String iso) => DateTime.parse(iso);
}
```

#### 4. 添加MessageSender映射
```dart
// lib/utils/sender_mapper.dart
class SenderMapper {
  // 后端 → 前端
  static MessageSender fromBackend(String sender) {
    if (sender == 'assistant' || sender == 'system') {
      return MessageSender.bot;
    }
    return MessageSender.user;
  }
  
  // 前端 → 后端
  static String toBackend(MessageSender sender) {
    return sender == MessageSender.user ? 'user' : 'assistant';
  }
}
```

```dart
// lib/services/backend_session_service.dart
class BackendSessionService {
  static const String baseUrl = "http://localhost:8000/api/v2";
  
  // 获取所有会话 - ✅ 无需user_id
  static Future<List<Project>> loadFromBackend() async {
    final response = await http.get(
      Uri.parse('$baseUrl/sessions'),
    );
    
    if (response.statusCode == 200) {
      final data = jsonDecode(response.body);
      final sessions = data['sessions'] as List;
      return sessions.map((s) => _parseSession(s)).toList();
    }
    
    return [];
  }
  
  // 创建会话 - ✅ 无需user_id
  static Future<Project?> createSession(String title, String icon) async {
    final response = await http.post(
      Uri.parse('$baseUrl/sessions/create'),
      headers: {'Content-Type': 'application/json'},
      body: jsonEncode({'title': title, 'icon': icon}),
    );
    
    if (response.statusCode == 200) {
      final data = jsonDecode(response.body);
      return _parseSession(data['session']);
    }
    
    return null;
  }
  
  // 解析Session数据（带映射）
  static Project _parseSession(Map<String, dynamic> json) {
    return Project(
      id: json['id'],
      title: json['title'],
      progress: json['progress'].toDouble(),
      icon: json['icon'],
      status: StatusMapper.fromBackend(json['status']),  // ⭐ 状态映射
      createdAt: TimeConverter.fromIso(json['created_at']),  // ⭐ 时间转换
      updatedAt: TimeConverter.fromIso(json['updated_at']),  // ⭐ 时间转换
      messages: (json['messages'] as List)
          .map((m) => _parseMessage(m))
          .toList(),
    );
  }
  
  // 解析Message数据（带映射）
  static Message _parseMessage(Map<String, dynamic> json) {
    return Message(
      id: json['id'],
      content: json['content'],
      type: MessageType.values.byName(json['type']),
      sender: SenderMapper.fromBackend(json['sender']),  // ⭐ Sender映射
      timestamp: TimeConverter.fromIso(json['timestamp']),  // ⭐ 时间转换
      mediaPath: json['media_path'],
    );
  }
}
```
