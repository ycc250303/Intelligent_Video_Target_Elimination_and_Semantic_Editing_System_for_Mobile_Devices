# 单用户模式简化方案（Demo版本）

## 🎯 设计目标

针对demo展示场景，简化后端架构，去除多用户支持，实现前后端数据模型的最大一致性。

---

## 📋 简化策略

### 移除的功能
1. ❌ 多用户支持
2. ❌ user_id字段及相关逻辑
3. ❌ 用户会话索引（user_sessions）
4. ❌ 复杂的会话ID格式

### 保留的功能
1. ✅ 多会话管理
2. ✅ 并发任务处理
3. ✅ 会话持久化
4. ✅ CRUD操作

### 后端模型（简化版）

```python
@dataclass
class Session:
    id: str                    # 简化的会话ID ⭐ 从 session_user123_xxx 变为 session_xxx
    title: str                # 标题
    icon: str                 # 图标emoji
    status: SessionStatus     # 状态枚举
    created_at: str           # ISO8601字符串
    updated_at: str           # ISO8601字符串
    messages: List[Message]   # 消息列表
    progress: float           # 进度 0.0-1.0
    current_video: Optional[str] = None      # 当前视频路径（可选）
    metadata: Dict[str, Any] = field(default_factory=dict)  # 元数据（可选）
```

**移除的字段**：
- ~~`user_id: str`~~ ❌ 不再需要

**字段变化**：
- `id`: 从 `session_user123_1234567890_abc123` → `session_1234567890_abc123`

### SessionManager（简化版）

```python
class SessionManager:
    """简化的单用户会话管理器"""
    
    def __init__(self, data_dir: str = "data/sessions"):
        self.sessions: Dict[str, Session] = {}  # session_id -> Session
        # ❌ 移除：self.user_sessions: Dict[str, List[str]]
        self.data_dir = Path(data_dir)
        self._lock = threading.Lock()
        self._load_all_sessions()
    
    def create_session(self, title: str, icon: str = "🎬") -> Session:
        """创建会话 - 不再需要user_id参数"""
        session_id = self._generate_session_id()  # 简化的ID生成
        
        session = Session(
            id=session_id,
            # ❌ 移除：user_id=user_id,
            title=title,
            icon=icon,
            status=SessionStatus.ACTIVE,
            created_at=datetime.now().isoformat(),
            updated_at=datetime.now().isoformat(),
            messages=[],
            progress=0.0
        )
        
        with self._lock:
            self.sessions[session_id] = session
            # ❌ 移除用户索引更新逻辑
            self._save_session(session)
        
        return session
    
    def get_all_sessions(self) -> List[Session]:
        """获取所有会话 - 不再需要user_id过滤"""
        with self._lock:
            sessions = list(self.sessions.values())
            sessions.sort(key=lambda s: s.updated_at, reverse=True)
            return sessions
    
    def _generate_session_id(self) -> str:
        """生成简化的会话ID"""
        timestamp = int(time.time())
        random_suffix = uuid.uuid4().hex[:8]
        return f"session_{timestamp}_{random_suffix}"
        # 旧格式：f"session_{user_id}_{timestamp}_{random_suffix}"
```

```dart
// lib/services/backend_session_service.dart
class BackendSessionService {
  static const String baseUrl = "http://localhost:8000/api/v2";
  
  // 获取所有会话 - 无需user_id
  static Future<List<Project>> loadFromBackend() async {
    final response = await http.get(
      Uri.parse('$baseUrl/sessions'),
    );
    
    if (response.statusCode == 200) {
      final data = jsonDecode(response.body);
      final sessions = data['sessions'] as List;
      return sessions.map((s) => Project.fromBackendJson(s)).toList();
    }
    
    return [];
  }
  
  // 创建会话 - 无需user_id
  static Future<Project?> createSession(String title, String icon) async {
    final response = await http.post(
      Uri.parse('$baseUrl/sessions/create'),
      headers: {'Content-Type': 'application/json'},
      body: jsonEncode({'title': title, 'icon': icon}),
    );
    
    if (response.statusCode == 200) {
      final data = jsonDecode(response.body);
      return Project.fromBackendJson(data['session']);
    }
    
    return null;
  }
}
```
