# 人格卡产品设计说明（大白话版）

## 一、什么是人格卡？

**简单说**：就是一个记录你剪辑习惯的"笔记本"。

- 你剪100个视频
- 系统发现你80%的时候都用"电影感调色"
- 下次自动推荐给你

```
后端（程序员）：我做好了人格卡系统！✅

用户（你）：我啥也没看到！❓
```

**核心问题**：功能做了，但界面上看不到，等于白做。

## 四、给程序员看的技术要点

### 后端改动（很小）

1. **在 session_api.py 添加推荐接口**：
```python
@session_app.post("/sessions/{session_id}/recommendations")
async def get_recommendations(session_id: str, video_metadata: dict):
    recommendations = video_executor.get_recommendations(
        video_metadata=video_metadata,
        user_id="default_user"
    )
    return {"recommendations": recommendations}
```

2. **就这么简单！** 因为推荐逻辑已经在 `persona_manager` 里做好了。

### 前端改动（也不大）

1. **添加服务方法**（`backend_session_service.dart`）：
```dart
static Future<List<Map<String, dynamic>>> getRecommendations({
  required String sessionId,
  Map<String, dynamic>? videoMetadata,
}) async {
  final response = await http.post(
    Uri.parse('$baseUrl/sessions/$sessionId/recommendations'),
    body: jsonEncode({'video_metadata': videoMetadata ?? {}}),
  );
  return jsonDecode(response.body)['recommendations'];
}
```

2. **添加UI组件**（新建 `recommendation_chips.dart`）：
```dart
class RecommendationChips extends StatelessWidget {
  final List<Map<String, dynamic>> recommendations;
  
  @override
  Widget build(BuildContext context) {
    return Wrap(
      children: recommendations.map((rec) {
        return ActionChip(
          label: Text('${rec['action']} ${rec['confidence']}%'),
          onPressed: () => onTap(rec['action']),
        );
      }).toList(),
    );
  }
}
```

3. **在 clip_page.dart 调用**：
```dart
// 上传视频后
final recommendations = await BackendSessionService.getRecommendations(
  sessionId: _currentProjectId,
  videoMetadata: {'duration': 60, 'category': 'vlog'},
);

// 显示推荐卡片
setState(() {
  _recommendations = recommendations;
  _showRecommendations = true;
});
```

## 八、FAQ

**Q：人格卡数据从哪来？**
A：用户每次剪辑，后端自动记录。现在已经在记录了，只是前端看不到。

**Q：推荐不准怎么办？**
A：用户刚开始用时确实不准（数据少），剪50个视频后就准了。可以显示"数据收集中，完成度 30/50"。

**Q：用户不想要推荐怎么办？**
A：可以加个"关闭推荐"开关。但默认打开，因为大部分用户会喜欢。

**Q：工作量大吗？**
A：不大！核心代码已经写好了，只是没有连接到前端界面。5小时就能完成。
