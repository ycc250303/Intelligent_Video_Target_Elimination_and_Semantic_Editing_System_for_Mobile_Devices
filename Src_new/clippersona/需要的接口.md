# 需要的接口

前端已重构，现在需要视频剪辑接口，接口有点多一切从简就好

都是ai根据项目生成的示例，具体参数和返回提供出来再调整

需要优先级：2.视频处理(上传+删除) > 3.通义api（先有一两个保证能接通）> 其他 > 登录

## 基础信息

- **Base URL**: `https://api.clippersona.com/api/v1`
- **Content-Type**: `application/json`
- **字符编码**: UTF-8

---

## I. 用户认证与管理

### 1. 用户注册

**接口地址**: `POST /auth/register`

**请求参数**:

```json
{
  "username": "user123",
  "email": "user@example.com",
  "password": "password123",
  "avatar": "base64_encoded_image" // 可选
}
```

**响应示例**:

```json
{
  "success": true,
  "message": "注册成功",
  "data": {
    "userId": "uuid-user-id",
    "username": "user123",
    "email": "user@example.com",
    "avatarUrl": "https://cdn.example.com/avatars/uuid.jpg",
    "token": "jwt-token",
    "expiresIn": 3600
  }
}
```

### 2. 用户登录

**接口地址**: `POST /auth/login`

**请求参数**:

```json
{
  "identifier": "user@example.com", // 支持邮箱或用户名
  "password": "password123"
}
```

**响应示例**:

```json
{
  "success": true,
  "message": "登录成功",
  "data": {
    "userId": "uuid-user-id",
    "username": "user123",
    "email": "user@example.com",
    "avatarUrl": "https://cdn.example.com/avatars/uuid.jpg",
    "token": "jwt-token",
    "expiresIn": 3600
  }
}
```

### 3. 获取用户资料

**接口地址**: `GET /user/profile`

**请求头**: `Authorization: Bearer <jwt-token>`

**响应示例**:

```json
{
  "success": true,
  "data": {
    "userId": "uuid-user-id",
    "username": "user123",
    "email": "user@example.com",
    "avatarUrl": "https://cdn.example.com/avatars/uuid.jpg",
    "createdAt": "2024-01-01T00:00:00Z",
    "lastLoginAt": "2024-01-15T10:30:00Z"
  }
}
```

### 4. 更新用户资料

**接口地址**: `PUT /user/profile`

**请求头**: `Authorization: Bearer <jwt-token>`

**请求参数**:

```json
{
  "username": "new_username",
  "avatar": "base64_encoded_image" // 可选
}
```

## II. 视频管理

### 1. 上传视频（有空的话弄图片，因为有图生视频）

**接口地址**: `POST /videos/upload`

**请求头**:

- `Authorization: Bearer <jwt-token>`
- `Content-Type: multipart/form-data`

**请求参数**:

- `file`: 视频文件
- `title`: 视频标题
- `description`: 视频描述（可选）

**响应示例**:

```json
{
  "success": true,
  "message": "视频上传成功",
  "data": {
    "videoId": "uuid-video-id",
    "title": "我的视频",
    "originalUrl": "https://cdn.example.com/videos/original/uuid.mp4",
    "thumbnailUrl": "https://cdn.example.com/thumbnails/uuid.jpg",
    "duration": 120,
    "fileSize": 10485760,
    "status": "uploaded",
    "createdAt": "2024-01-15T10:30:00Z"
  }
}
```

### 2. 获取用户视频列表

**接口地址**: `GET /videos`

**请求头**: `Authorization: Bearer <jwt-token>`

**查询参数**:

- `page`: 页码（默认1）
- `limit`: 每页数量（默认20）
- `status`: 视频状态（uploaded, processing, completed, failed）

**响应示例**:

```json
{
  "success": true,
  "data": {
    "videos": [
      {
        "videoId": "uuid-video-1",
        "title": "我的视频",
        "thumbnailUrl": "https://cdn.example.com/thumbnails/uuid.jpg",
        "duration": 120,
        "status": "completed",
        "createdAt": "2024-01-15T10:30:00Z"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 100,
      "totalPages": 5
    }
  }
}
```

### 3. 获取视频详情

**接口地址**: `GET /videos/{videoId}`

**请求头**: `Authorization: Bearer <jwt-token>`

### 4. 删除视频

**接口地址**: `DELETE /videos/{videoId}`

**请求头**: `Authorization: Bearer <jwt-token>`

## III. 通义视频模型API（优先）

### 1. 图生视频 - 基于首帧

**接口地址**: `POST /video-process/image-to-video/first-frame`

**请求头**: `Authorization: Bearer <jwt-token>`

**请求参数**:

```json
{
  "sourceVideoId": "uuid-source-video",
  "imageUrl": "https://cdn.example.com/images/input.jpg",
  "duration": 10,
  "style": "realistic"
}
```

**参数说明**:

- `style`: realistic, artistic, cartoon

### 2. 图生视频 - 基于首尾帧

**接口地址**: `POST /video-process/image-to-video/first-last-frame`

**请求头**: `Authorization: Bearer <jwt-token>`

**请求参数**:

```json
{
  "sourceVideoId": "uuid-source-video",
  "firstFrameUrl": "https://cdn.example.com/images/first.jpg",
  "lastFrameUrl": "https://cdn.example.com/images/last.jpg",
  "duration": 15,
  "transition": "smooth"
}
```

**参数说明**:

- `transition`: smooth, fade, cut

### 3. 图生视频 - 视频特效

**接口地址**: `POST /video-process/image-to-video/effects`

**请求头**: `Authorization: Bearer <jwt-token>`

**请求参数**:

```json
{
  "sourceVideoId": "uuid-source-video",
  "imageUrl": "https://cdn.example.com/images/input.jpg",
  "effectType": "slow_motion",
  "effectParams": {
    "speed": 0.5,
    "intensity": 0.8
  }
}
```

**参数说明**:

- `effectType`: slow_motion, fast_forward, reverse, zoom

### 4. 文生视频

**接口地址**: `POST /video-process/text-to-video`

**请求头**: `Authorization: Bearer <jwt-token>`

**请求参数**:

```json
{
  "prompt": "一个未来城市，飞行汽车在夕阳下穿梭，电影级画质",
  "duration": 10,
  "aspectRatio": "16:9",
  "style": "cinematic",
  "resolution": "1080p"
}
```

**参数说明**:

- `aspectRatio`: 16:9, 9:16, 1:1
- `style`: cinematic, realistic, artistic
- `resolution`: 720p, 1080p, 4k

### 5. 通用视频编辑

**接口地址**: `POST /video-process/edit`

**请求头**: `Authorization: Bearer <jwt-token>`


## IV. 任务状态管理

### 1. 查询任务状态

**接口地址**: `GET /tasks/{taskId}`

**请求头**: `Authorization: Bearer <jwt-token>`

**响应示例**:

```json
{
  "success": true,
  "data": {
    "taskId": "uuid-task-id",
    "status": "completed",
    "progress": 100,
    "resultVideoId": "uuid-result-video",
    "resultVideoUrl": "https://cdn.example.com/videos/processed/uuid.mp4",
    "thumbnailUrl": "https://cdn.example.com/thumbnails/uuid.jpg",
    "errorMessage": null,
    "createdAt": "2024-01-15T10:30:00Z",
    "completedAt": "2024-01-15T10:35:00Z"
  }
}
```

**状态说明**:

- `pending`: 等待处理
- `processing`: 处理中
- `completed`: 处理完成
- `failed`: 处理失败

### 2. 获取用户任务列表

**接口地址**: `GET /tasks`

**请求头**: `Authorization: Bearer <jwt-token>`

**查询参数**:

- `page`: 页码（默认1）
- `limit`: 每页数量（默认20）
- `status`: 任务状态

### 3. 取消任务

**接口地址**: `POST /tasks/{taskId}/cancel`

**请求头**: `Authorization: Bearer <jwt-token>`
